# Showtime Background Library

这一目录放通用背景层。它们的目的不是替代专业年表，而是在用户导入一个研究主题后，快速提供可比较的历史、思想、区域、技术和长尺度背景。

CSV 格式仍然是 `time,title`。时间可以是年份、区间，或当前工具支持的公元日期 `YYYY-MM-DD`。

这些背景层适合先作为研究参照使用；精确到具体日期的事件仍建议在专题 CSV 中单独维护。

当前本地库包含 74 个背景层：

- 长尺度：Big History、地质生命史、人类迁徙与人口、农业与驯化、气候环境事件
- 通用政治史：中国朝代、世界帝国、欧洲时代、世界史分期、主要战争、殖民主义与去殖民化、政治革命、民主化、法律与人权
- 区域背景：伊斯兰世界、南亚、日本、朝鲜半岛、东南亚、非洲、美洲、欧亚草原、古代近东与埃及、大洋洲与太平洋世界
- 区域细分：波斯与伊朗、中亚与丝路腹地、巴尔干与东南欧、南美洲、北欧、东欧与俄罗斯、藏区与内亚
- 中国专题：中国思想史、中国科技史、中国文学史、中国经济史、中国艺术史
- 知识文化：思想史运动、宗教史、文学艺术、教育与知识机构、文字媒介、语言文字与翻译、医学与公共卫生、天文学与空间探索
- 学科内史：数学、逻辑 / 计算 / 人工智能、物理学、化学、生物学与演化论、经济思想、心理学与认知科学、地理与制图
- 艺术与日常：音乐、建筑、戏剧与表演、电影与影像、饮食、服饰与时尚、体育与竞技
- 社会制度与身份：货币与度量衡、法典与成文法、女性史、儿童与家庭、瘟疫与大流行、灾害与地震、环境保护运动
- 社会技术经济：科学技术史、贸易网络、经济社会史、资本主义与金融体系、交通运输、能源史、城市化、劳动制度 / 社会运动 / 性别

完整的逐层覆盖矩阵、空白分析与扩库候选见 [`docs/background-library.md`](../docs/background-library.md)。Manifest 的合法 tags、regions、scale 与 density 见 [`VOCABULARY.md`](VOCABULARY.md)；机器检查使用 [`vocabulary.json`](vocabulary.json)。

## 维护约束

- 每个 CSV 只含 `time,title` 两列；数据前可放 `#` 注释。
- 注释头必须写明用途、来源框架，并声明“用于研究定位与比较，不是权威或完整年表”。
- 默认保持 15–40 条朝代级、思潮级或里程碑级事件；不要把背景层写成残缺的细年表。
- 新增层时同时更新 `manifest.json`、本文件和覆盖矩阵；新增 tag / region 必须先登记受控词表。
- 有争议的起止时间使用近似区间，不用虚构的精确日期。

## 选层参考框架

这些层的取舍优先服务“研究背景”而不是单一学科完整性。扩展或校订时可优先参考：

- College Board AP World History: Modern 的全球史主题和 1200 年以来的常用单元框架
- International Commission on Stratigraphy 的国际地质年代表
- Our World in Data 的人口、经济、能源、健康、技术等长时段数据项目
- WHO 的公共卫生里程碑
- NASA 的空间探索和月球探索时间线
- IEA 的能源安全与能源转型历史说明
