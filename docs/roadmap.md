## 下一阶段：校订质量，而不是追求层数

### 1. 背景库治理与来源可追溯性

当前 79 层已经覆盖通史、主要区域、学科、艺术日常、社会制度、中国专题和现代系统。下一步不设“越多越好”的数量目标，优先建立可重复校订流程：

- 给每层建立稳定的来源框架版本、最后复核时间与争议说明，而不把版权年表正文复制进仓库。
- 用覆盖矩阵识别真正影响比较的空白；不机械填充没有研究意义的“学科 × 尺度”格子。
- 对快速变化的当代层定期冻结明确终点或说明开区间，避免同一项目在不同年份得到无提示的范围漂移。
- 为区域与主题别名增加成对测试，审查误报、漏报和地区命名的历史语境。

候选审查队列包括北美 / 加勒比 / 中美洲的拆分、非洲次区域、阿拉伯世界与奥斯曼专题，以及口述传统、原住民知识、残障史和迁徙离散等横向主题。它们只有在能提供 15–40 条稳定宏观骨架、明确来源框架和通用比较价值时才应进入 Manifest。

验收条件：每一批独立提交；CSV、Manifest、受控词表、README、覆盖矩阵同步；仓库测试证明无孤儿文件、非法元数据或时间解析漂移。

### 2. 推荐校准与可观察性

- 展示“为何未推荐”的诊断摘要，例如无时间交集、尺度悬殊或索引失败。
- 允许用户明确指定哪些图层代表专题范围，避免手动加入的超长背景层反过来扩大推荐时间窗。
- 研究是否把拒绝列表保存进项目；在格式演进前先定义兼容与迁移语义。
- 用不同地区、语言、尺度和空项目的固定样本建立排名回归集，不引入不可解释的学习模型。
- 若预生成背景范围索引，应由质量门从 CSV 生成并校验，不能维护第二份手工真相。

验收条件：相同输入稳定排序；分数明确只是匹配分；错误和缺失数据不触发自动加载；完整手动列表始终可用。

### 3. 更强的比较查询

- 图层对 / 分组对的交集、先后与空白区间摘要。
- 围绕探针生成“之前 / 同时 / 之后”的可导出研究摘记。
- 把统计从单纯事件计数扩展到可解释的持续时间、覆盖范围和元数据完整度，同时继续警告“记录数不等于历史强度”。
- 保存比较条件到命名视图和项目包，并保证 round-trip。

验收条件：查询逻辑保持纯函数；结果可追溯到具体事件；Canvas 和文本面板给出等价操作入口。

### 4. 可访问性、性能与恢复

- 为 Canvas 当前视窗提供更完整的键盘可遍历文本镜像。
- 建立 1 万、10 万事件的分级性能基准，记录设备条件和降级行为。
- 增加导入前容量估算、存储配额提示和显式备份提醒。
- 扩展 Chrome 之外的现代浏览器验证矩阵，而不依赖运行时 polyfill CDN。

验收条件：桌面与 390 px 触屏无横向溢出；控制台无错误；`prefers-reduced-motion`、高 DPI 和焦点可见性不退化。

## 后续探索

- 可安装的本地背景包与个人背景库，但必须保留明文 CSV、Manifest 检查和卸载边界。
- 项目级关系注释，例如“影响”“回应”“同时发生”；关系必须可导出，不能只存在于画布像素中。
- 可选的在线或 LLM 辅助背景草案。若未来单独立项，必须默认关闭、明确联网与数据发送范围、标注生成来源，并把结果落成用户可检查和编辑的具体 CSV；它永远不能替代本地库或手动加载。

## 明确不做

- 不要求账号、后端或云数据库才能使用核心工作流。
- 不把主 CSV 扩成必填元数据表，也不放弃旧 ZIP 兼容。
- 不引入运行时框架、CDN 或构建产物作为 GitHub Pages 发布前提。
- 不把推荐分、事件数量或可视密度表述成史实可信度、重要性或因果关系。
- 不把时间轴退化为一次生成、无法检查和重排的静态图表。
